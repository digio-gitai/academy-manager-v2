## 메뉴 통합 (2026-08-22)
실제 운영 스트림릿 앱(`app_layout.py`의 `FERMA_MENU`, 로컬 파일 직접 확인)의 진짜 메뉴는 13개: 대시보드, 내 수업 관리, 학생 명부, 출석 관리, 출석부 만들기, 수강료 관리, 상담 일지, 성적 리포트, 기출문제분석, 문제 은행, 과제 인증, 학사정보, 설정.

React 시안 사이드바는 원래 5개(출결관리/성적입력/리포트생성/과제인증/설정)뿐이었고 이름도 스트림릿과 약간 다르게 붙어있어서, 앞으로 8~11개 화면을 더 만들기 전에 사용자와 함께 정리함. 확정된 내용:
- **출석 관리 + 출석부 만들기 → 하나로 합침.** "출석부 만들기"는 출석 데이터로 인쇄용 출석부를 만드는 기능이라, React에서는 "출석 관리" 화면 안의 기능(버튼/탭)으로 들어갈 예정 — 별도 메뉴로 안 만듦.
- **기출문제분석 + 문제 은행 → 별도 메뉴로 유지.** 목적이 다름(기출문제분석=출제경향 분석, 문제 은행=OCR로 문제집 등록·검수).
- **성적입력(React 시안에만 있던 항목) → "성적 리포트" 하나로 합침.** 스트림릿에도 "성적입력"이라는 별도 메뉴는 없고, "성적 리포트" 메뉴 안에 탭(성적조회/학교시험/모의고사/AI분석/통합보고서)으로 이미 들어있음 — React "리포트생성"을 "성적 리포트"로 이름도 맞춤.
